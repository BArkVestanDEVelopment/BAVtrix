# BAVtrix

Digital rain for the desktop and the phone: falling streams of glyphs with depth, flicker
and your own picture showing through the symbols.

Цифровой дождь для рабочего стола и телефона: потоки символов с глубиной и мерцанием,
сквозь которые проступает ваша картинка.

## Platforms

| Platform | State |
|----------|-------|
| Windows 10/11 | Released (1.0): desktop layer, screensaver, installer with autostart |
| macOS | Menu bar app (desktop-level rain) and screensaver |
| iOS | App with the rain and settings (iOS has no API for home-screen wallpapers) |
| Android | App, live wallpaper and daydream |

## Windows

- Desktop mode: the rain is drawn between the wallpaper and the windows, hides the desktop icons
  and reveals only hovered or selected ones. The wallpaper shows through the glyphs.
- Screensaver (`bavtrix.scr /s`) and a settings window (`bavtrix.exe /c` or the tray icon).
- Per-monitor DPI and several monitors; settings are kept in `default.cfg` next to the program.
- Setup program with a choice of install folder, autostart and shortcuts; per-user, no admin rights.

### Build

Rust (stable, `x86_64-pc-windows-gnu` or MSVC toolchain):

```
cd bmatrix
cargo build --release          # bavtrix.exe
```

The installer embeds the release files, so build the app first and put `bavtrix.exe`,
`README.txt` and `LICENSE.TXT` into `release/1.0/`, then:

```
cd installer
cargo build --release          # bavtrix-setup.exe
```

## Layout

- `bmatrix/` — the Windows application (Rust, Win32 via `windows-sys`)
- `installer/` — the Windows setup / uninstall program
- `apple/` — Swift core, iOS app, macOS app and screensaver (Xcode project generated by XcodeGen)
- `android/` — Android app, live wallpaper and daydream (Kotlin, Jetpack Compose)
- `legal/` — licence texts shown in the apps ("Licenses" screen)
